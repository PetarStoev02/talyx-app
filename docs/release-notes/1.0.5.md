## Talyx 1.0.5

1.0.5 gives add-on modules what the new Workflows needs: your bots' faces, a place in the sidebar's `+`, chat messages that wait their turn, and a tidy chat.

- **Module messages wait their turn.** A message a module sends to a bot that is busy now waits for the bot's current turn to end, instead of cutting into it. Several tasks can run through the same bots at once without talking over each other.
- **Your bots' block avatars on module pages.** Modules can draw the same isometric blocks the roster shows, in each bot's own shape and color.
- **The sidebar's `+` follows the section.** On a module's page, `+` offers that module's own actions (for Workflows: New task and New workflow); on Agents it still adds a bot, a room or a folder.
- **Workflows messages read cleanly in the chat.** A Workflows brief shows as a small card you can open, and the status lines the bots post show as compact rows.
- **Cleaner module pages.** Module pages no longer repeat their name above the page, and the Agents and module switch has no icons.

Without a license key nothing changes.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.4 or 1.0.3:** the update button shows "Talyx 1.0.5 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.5 needs engine 0.22.7, the same as 1.0.4. Nothing changes for an engine that is already installed.
