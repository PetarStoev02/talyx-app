## Talyx 1.0.1

1.0.1 makes Talyx easier to install and keep up to date, and fixes what came up in the first days of 1.0.

- **Signed and notarized on macOS.** The Mac builds are signed with Developer ID and notarized by Apple. macOS opens them without a warning, so the Open Anyway step is gone.
- **Updates install themselves on macOS and in the AppImage.** Talyx downloads a new release in the background, checks it, and installs it when you click **Restart to update** or quit. It never restarts on its own. A deb install keeps the link to the release page.
- **Routines you can open.** Click a routine to see its next and last run and its recent runs, edit it, or run it now.

## Fixes

- Bots can switch to a custom endpoint and back, and the endpoint shows once in the model menus and in Settings.
- Every bot knows it lives in Talyx.
- Your messages show what you typed, without text the engine added. Tool lines show only while a bot works.
- Save errors look like errors and say which field failed. Refresh roster shows that it ran.
- Dictation explains that it needs a speech-to-text provider.
- Images from remote addresses in a bot's reply are not loaded.
- The engine debug console moved into Settings → Engine. The alpha badge is gone.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.0:** click Download in the update button once. 1.0.0 opens the installer for you; on a Mac, drag the new Talyx over the old one. From 1.0.1 on, updates install themselves on macOS and in the AppImage.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.1 needs engine 0.22.7, the same as 1.0.0. Nothing changes for an engine that is already installed.
