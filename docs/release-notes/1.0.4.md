## Talyx 1.0.4

1.0.4 gives add-on modules room in the sidebar and a way to talk to your bots.

- **Agents and modules side by side.** With a module installed, the sidebar has a switch between your agents and your modules. A module can draw its own sidebar while its page is open, and the agents' list comes back with one click.
- **Modules can message your bots.** A module's page can send a bot a message and read its replies, through the same chat you type in: the message shows in the bot's chat, and Talyx asks you for approvals as usual.

Without a license key nothing changes: there is no switch, no new section and no network call.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.3:** the update button shows "Talyx 1.0.4 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.4 needs engine 0.22.7, the same as 1.0.3. Nothing changes for an engine that is already installed.
