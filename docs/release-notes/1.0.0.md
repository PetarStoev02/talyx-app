## Talyx 1.0

Talyx is a desktop app to tally your AI agents: a roster of bots on the left, one chat on the right, and a manager bot, Talyx, that hands work to the other bots and briefs you. The bots run on the engine, a separate agent backend on your computer. Talyx's first-run setup installs it for you, for your user only, with no admin password.

1.0 is the first build meant for daily use:

- A roster with pins, folders, unread marks and what each bot is doing.
- One chat per bot: approvals and questions as cards, images, dictation, and a choice of model and reasoning.
- Bot details: title, description, model, routines, look and SOUL. Create bots from the roster.
- Group rooms where several bots answer in one conversation.
- Settings: model providers (API keys, account sign-ins, custom endpoints), the engine, launch at login, and the theme.

## Install

No build is signed or notarized: there is no Apple developer account and no Windows certificate. Your system warns you the first time you open each new version.

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG and drag Talyx to Applications. Open Talyx and dismiss the warning. Then go to System Settings → Privacy & Security, scroll down and click **Open Anyway**; macOS asks for your password. Or run once in Terminal: `xattr -dr com.apple.quarantine /Applications/Talyx.app`
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`. In-app updates download the AppImage.

Later versions are announced in the app: click Download and Talyx fetches the installer for your computer, checks it against this release's `SHA256SUMS`, and opens it for you.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`.

## The engine

Talyx 1.0 needs engine 0.22.7, and its setup installs exactly that version from the install steps attached to this release (`engine-install.json`), checked against a copy built into Talyx. Engine updates arrive with Talyx releases: when a new Talyx needs a newer engine, it offers to update it.

## Not in 1.0

- **Windows.** No Windows build yet; it comes once the engine runs there.
- **Remote engines.** Talyx attaches only to an engine on the same computer.
- **Reasoning blocks.** The model's reasoning is not shown in the transcript.
- **Voice mode.** You can dictate a message, but there are no spoken conversations.
- **Other languages.** The app is in English only.
