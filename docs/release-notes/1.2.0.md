## Talyx 1.2.0

1.2 lets a bot show an interface in its answer, gives you a second sidebar layout, shows module updates beside Talyx's own, and lets outside agents do much more with your bots.

- **Interfaces in a bot's answer.** A bot can put a small interface in its chat: text, number tiles, charts, tables, buttons, choices and a form. Talyx draws it from its own components, so no code from the bot runs. A click or a sent form goes back to the bot as your next message, and the card stays in the chat after a restart.
- **A Layered sidebar.** Settings, General, Appearance has a Layout choice. Dock keeps today's sidebar with the pages in a dock at its foot. Layered puts a rail of pages beside the sidebar, with a fold button and the page as a card.
- **Module updates in the update button.** A new version of an installed module shows in the footer's update button, the same way a Talyx or engine update does, with an Update button.
- **More for outside agents.** Talyx's MCP server has new tools. An agent can now:
  - chat with one bot and read its replies;
  - read, edit, run and look at the past runs of a bot's routines;
  - read and change a bot's memories and skills;
  - hide or show a bot, and read usage.

  Tools that change or delete something ask you in Talyx first.

- **Fixes.**
  - When one bot hands work to another, those messages no longer fill your chat with the bot. Each shows as one quiet line you can open.
  - Until the engine is attached, the window shows only the engine screen, without a sidebar, Settings or Usage that could not work.
  - A chat opened for the first time no longer misses a message that arrives while it loads.
  - Right-clicking inside a row's open menu no longer freezes the window. Shortcuts wait while a menu is open, names are capped at 24 characters, and Talyx's own bot stays pinned.
- **Under the hood.** More of the app's rules are now checks that run on every change.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.3 or later:** the update button shows "Talyx 1.2.0 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.2.0 needs engine 0.22.7, the same as 1.1.1. The engine itself is not changed.
