## Talyx 1.0.2

1.0.2 is a bug-fix release. It fixes what the first Linux testers found and makes failures easier to understand.

- **Linux works like a desktop app.** The window has its native frame again (resize, minimize, maximize, close), and the AppImage starts without FUSE 2 (`libfuse.so.2`).
- **Failed and stopped turns stay in the chat.** A failed send shows your message and the engine's reason. A stopped reply keeps its text, labeled "Stopped". A provider wait (rate limit) shows in the activity line with its retry time.
- **Version and diagnostics in Settings.** Settings → About shows the Talyx and engine versions. **Copy diagnostics** copies them with the OS and the recent log, with keys, tokens and passwords removed.

## Fixes

- Code blocks in a bot's reply have a copy button, and long code lines wrap.
- A slow engine answer during a sign-in shows as a timeout, not a lost connection, and the sign-in keeps going.
- An engine install that stops on a download error explains that it is usually the network (VPN, proxy) and that trying again keeps finished parts.
- Setup notices an engine or provider set up outside it, and the ready screen keeps the install output.
- Clearer hints: each bot keeps its own model, the endpoint check says how many models it lists, the routine toggle says it sends results to the chat, and ChatGPT sign-in explains device-code sign-in.
- Check again in Settings → Engine shows when it last checked.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.1:** Talyx downloads the update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.2 needs engine 0.22.7, the same as 1.0.1. Nothing changes for an engine that is already installed.
