## Talyx 1.0.6

1.0.6 moves the pages into a small dock in the sidebar's footer, splits Settings into pages, and makes updates and module keys harder to tamper with.

- **A dock in the footer.** The tabs at the top of the sidebar are gone. With a module installed, the footer has a dock with Agents and each module, each drawn as a small block; the open page sits on a disc that slides between them. ⌘1, ⌘2 and so on open them in order (Ctrl on Linux). Without a module there is no dock: the footer is Settings and refresh, as before.
- **Settings in pages.** General (theme, launch at login, setup), Providers, Engine, Modules and About each have their own page, picked from Settings' own sidebar. "Open settings" in the chat goes straight to Providers.
- **Updates only from a feed Talyx signed.** On macOS and in the AppImage, Talyx now downloads an update only when the release's update feed carries Talyx's own signature, made with a key that is never on GitHub. A release someone else publishes on the repository cannot update your Talyx.
- **Module keys and links hardened.** License keys and `talyx://activate` links are checked more strictly, and a key can now unlock every module, including ones released later.
- **Module pages can ask before you leave.** A module page holding unsaved work can ask before Talyx switches away from it.

Talyx is now licensed under the AGPL-3.0 from this release on; 1.0.5 and earlier stay MIT. Without a license key nothing about modules shows.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.5, 1.0.4 or 1.0.3:** the update button shows "Talyx 1.0.6 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.6 needs engine 0.22.7, the same as 1.0.5. Nothing changes for an engine that is already installed.
