## Talyx 1.1.0

1.1 lets you see what your bots spend, look inside a bot's memory and skills, search a chat, drop files into the composer, and drive Talyx from the keyboard.

- **Usage.** A chart button next to the gear opens Usage: the tokens and requests every bot used over 7, 30 or 90 days, tokens per day, each provider's share and a breakdown by model, with a page per provider. A provider that reports nothing says so instead of showing zero.
- **A bot's memories and skills.** The details panel has a Memory tab. Read, search, edit and delete what a bot remembers, and see every skill it has. Open a skill to read or edit its instructions, turn it on or off, or delete one the bot made.
- **Search a chat.** ⌘F (Ctrl+F on Linux) searches the open chat and the rooms the bot is in. Matches are highlighted in place, and a list shows the messages found in each room; pick one to jump to it.
- **Drop or paste files.** Drag images, files and folders into the chat, or paste them. Images go to the bot as images; files and folders go as their paths.
- **Regenerate and retry.** Regenerate asks a bot for a new answer in place of its last one. A failed turn retries in place instead of sending the message again.
- **Keyboard shortcuts.** New bot, the previous and next bot or room, the message box, a page from the dock and more. ⌘/ (Ctrl+/ on Linux) shows them all.
- **Bots that follow Talyx's model.** A bot can be on Uses default, so it moves when you change Talyx's model in Settings. A model of its own stays put.
- **Routine runs.** Open a routine's run to read its output, or the error it ended with.
- **Custom endpoints.**
  - **Test chat** sends one short message through the engine with the endpoint's model, the way a bot does, and shows the reply or the provider's real error. It leaves no chat behind.
  - **Remove a model** from an endpoint. The change goes to every bot. A bot on the removed model keeps it and is flagged, so you choose its new model.
- **Arch Linux.** The AUR package `talyx-bin` is written and comes with each release; it goes on the AUR once published.
- **Smaller fixes.** The new screens were reviewed for readability, layout and screen readers. Usage fits a narrow window, ⌘F is no longer hidden behind an open details panel, hints and notices match what the app does, and status messages are announced.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.3 or later:** the update button shows "Talyx 1.1.0 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.1.0 needs engine 0.22.7, the same as 1.0.7. For Usage, Talyx adds a second small read-only plugin of its own to the engine's plugins folder, beside the one for rooms; the engine itself is not changed.
