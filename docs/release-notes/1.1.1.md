## Talyx 1.1.1

1.1.1 is a fix release.

- **A new bot starts on Talyx's model.** A bot made right after you changed Talyx's model, including the first bot in setup, could start on the previous model, or on none, and fail its first message. It now always starts on Talyx's model as it is.
- **Usage shows your own endpoints.** Tokens a bot spent through a custom endpoint, such as a local router, now show under that endpoint's name on the Usage page. Before, the endpoint said "No usage reported" and an unnamed `custom` row took everything.
- **Outside agents keep their key.** When Talyx could not read its saved MCP key, it made a new one, and every outside agent set up with the old key was locked out. Talyx now keeps the saved key, and starts even when the key file cannot be read.
- **Cards and chats stay current after a reconnect.** After the engine restarted or the connection dropped, an approval or clarify card that was already answered could stay on screen, and the roster kept saying the bot was waiting. A chat that reloaded at the wrong moment could also miss a message until the next answer. Both now catch up, and a reconnect no longer stops chats from resuming after a later drop.
- **Smaller fixes.**
  - Escape twice after the shortcuts sheet leaves Usage or Settings again; a tooltip no longer swallows the second Escape.
  - On Linux, when Talyx cannot restart into a downloaded update, it says so instead of doing nothing.
- **Under the hood.** Talyx's internals were reworked and hardened, with more checks on every change.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.3 or later:** the update button shows "Talyx 1.1.1 is available"; click **Download**, then **Restart to update**. **Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.1.1 needs engine 0.22.7, the same as 1.1.0. The Usage plugin Talyx adds to the engine's plugins folder is updated in place; the engine itself is not changed.
