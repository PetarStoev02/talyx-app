## Talyx 1.0.3

1.0.3 puts you in charge of updates and polishes every screen.

- **Updates wait for you.** Talyx no longer downloads an update on its own. The update button shows "Talyx 1.0.4 is available" with **Download** and **Later**, then a progress bar, then **Restart to update**. Talyx checks for updates shortly after it starts, every hour, and after the computer wakes.
- **Check for updates in Settings.** Settings → About has a **Check for updates** button. It says whether Talyx is up to date or which version is available.
- **Polished screens.** The roster list and the chat fade at an edge only while there is more to scroll. Pinned tiles fit longer names, unread dots no longer push the time out of line, and the Create button stays visible in a short window.

## Fixes

- Folder counts include rooms, so a folder that holds only rooms no longer shows 0.
- The details header shows the bot's model on its own line.
- Popovers keep a small gap from the window edge.
- Folder, provider and routine schedule menus match the other fields.
- Setup's Copy all and Copy output buttons match the buttons next to them.

## Add-on modules

Talyx can now install signed add-on modules unlocked by a license key, from **Enter License Key…** in the app menu. Without a key nothing changes: there is no new section, no new tab and no network call.

## Install

- **macOS 13 or newer** (Apple Silicon: `Talyx-arm64.dmg`, Intel: `Talyx-x64.dmg`). Open the DMG, drag Talyx to Applications and open it.
- **Linux (x64).** Download `Talyx-x86_64.AppImage`, make it executable with `chmod +x Talyx-x86_64.AppImage` and run it. Or install the deb with `sudo apt install ./Talyx-amd64.deb`.

**Coming from 1.0.2 or 1.0.1:** Talyx downloads this update in the background on macOS and in the AppImage; click **Restart to update** or quit. From 1.0.3 on, Talyx asks before it downloads. A deb install links to this page. **Coming from 1.0.0:** click Download in the update button once.

## Check your download

`SHA256SUMS` lists the SHA-256 of every file in this release. Put it in the folder with your download and run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`

Each file you downloaded should print `OK`. On a Mac, `spctl -a -vv /Applications/Talyx.app` should say `source=Notarized Developer ID`.

## The engine

Talyx 1.0.3 needs engine 0.22.7, the same as 1.0.2. Nothing changes for an engine that is already installed.
